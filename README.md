# 手指交互星空粒子系统 (Gesture Particle Universe)

复刻自抖音爆火的 Codex AI 交互 Demo。

## 🌟 核心特色与武器手势
- **无需复杂环境**：纯前端轻量架构，免编译免安装，打开即玩。
- **高精度双手 AI 姿态追踪**：基于 Google MediaPipe Hands 算法，本地实时 21x2 个 3D 骨骼点双手机制检测。
- **36,000 颗高精星尘粒子与专属武器形态**：
  1. 🔫 **粒子能量手枪 (Finger Gun & Laser Blaster)**：**拇指与食指比出手枪手势**（食指伸直向前、拇指耸立竖起、中指/无名指/小指蜷缩扣紧），全场 36,000 颗粒子瞬间聚拢拓扑重构为一把科幻能量手枪！
     - **瞄准追踪**：随手腕与食指方向实时 3D 倾角旋转瞄准；
     - **扣扳机开火**：拇指自然下压扣动扳机（或点击鼠标/按空格键），枪口喷射耀眼等离子闪光，向瞄准方向打出高速穿透激光爆能弹，并伴随真实机械后坐力震颤！
  2. 🗡️ **双指剑诀·万剑归宗 (Two-finger Sword)**：**食指与中指同时伸长并拢**（道家双指剑诀，其余手指扣拢），36,000 颗星尘粒子凝聚为一把璀璨等离子神剑，随双指朝向实时挥舞、劈砍、刺击！
  3. 🖐️ **掌心时空斥力盾 (Repulsor Shield)**：五指完全张开向前推，掌心释放强大反引力波，将粒子如浪潮般剧烈推开并激荡出明亮光晕！
  4. 🤏 **引力黑洞与双星虫洞 (Pinch & Wormhole)**：单手拇指食指捏合形成吸积盘黑洞；双手齐捏合拉出扭曲的爱因斯坦-罗森桥（时空虫洞桥梁）！
  5. 👏 **双手击掌时空激波 (Cosmic Clap Shockwave)**：双手在空中快速击掌合十，碰撞点瞬间引爆全屏环形激波，36,000 颗粒子剧烈震荡并激活全色谱闪耀！
  6. 💥 **超新星大爆发 (Supernova Burst)**：捏合/握拳聚能后突然猛烈张开手掌，星尘向全屏飞溅散射！
- **4套高精多波段光谱**：仙女座梦幻、赛博极光霓虹、炽烈恒星超新星、七彩虹光棱镜。
- **HUD 实时手势徽章与画中画**：顶部实时呈现左手与右手的当前技能状态识别（手枪激活时亮起高能红白武器徽章，画中画实时标记准星）。
- **全方位操控与模拟支持**：
  - 摄像头手势：比出手枪手势瞄准，拇指下压开火；比出双指剑诀挥舞神剑；
  - 底部控制栏：点击「🔫 能量手枪 (点击开火)」即可一键激活并点击连发射击；点击「🗡️ 两指剑诀」切换神剑；
  - 键盘快捷键：
    - `6` 或 `G`：开启/切换能量手枪形态；
    - 空格键 或 `F` 或 鼠标点击：开火发射激光爆能弹；
    - `5` 或 `S`：开启/切换双指神剑形态；
    - `1` 单指流星轨 / `2` 掌心斥力盾 / `3` 引力黑洞 / `4` 击掌激波。

## 🚀 启动方式
双击运行 `start.bat`，浏览器将自动打开 `http://localhost:8088/index.html`。首次打开请点击允许摄像头权限。
